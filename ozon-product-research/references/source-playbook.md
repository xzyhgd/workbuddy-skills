# 数据源与取证手册

## 证据优先级

1. 本店 Seller API 或后台可复核读数。
2. Ozon 前台 PDP、履约和买家评价原始内容。
3. 官方费率表、官方产品与合规材料。
4. 用户提供的供应商图纸、样品、报价和物流记录。
5. 第三方文章、论坛与社媒，只作为假设或反证来源。

每一条进入决策的证据都要记录查询词、日期、窗口、筛选、样本边界、核验城市和快照。

## 需求侧

- Wordstat：用于词形、转写、趋势和全网心智验证；不与 Ozon 站内数据相加或互推销量。
- Ozon 搜索与分析：使用对照词验证筛选通道，记录是否为 7 天词维度或 28 天商品维度。
- 商品维度成交：用于低频或高客单候选的商品级复测；Top 50 截断必须显式标注。
- 社媒与论坛：只生成痛点、词形和反证假设，不能独自支持需求规模结论。

## 竞争与履约侧

1. 先用多词检索找到候选，再逐条打开 PDP。
2. 记录标题、规格、包装、评价、价格、发货地、ETA 和物流方式。
3. 将原厂、高评价、境内 FBO 或次日达样本与跨境、第三方、白牌、浅评样本分层。
4. 统一为单件、单张或等效单位价格后再比较。
5. 不得把页面卡片的本地化类目文本直接当作实体判断；必要时核对 URL slug、PDP 规格和评价正文。

## 访问受限

- 遇到 307 自增挑战参数、403、Qrator、`abt_data`、Captcha 或滑块验证时，立即停止自动化读取。
- 不换代理、不求解挑战、不关闭 TLS 校验、不循环重试。
- 等待用户在自己的人工浏览器完成验证；验证前已取得的数据保留，但标注时间和范围。
- 无法恢复时，转为用户提供截图、导出或人工读数的离线分析。通道不可用不等于真实零值。

## 数据失效与复测

- 需求、价格、评价和履约：超过约 60 天重新采集。
- 汇率：按 `current-parameters.md` 的复核周期处理。
- 佣金、比例费和 OGL：结算单或官方费率表更新后重新校验。
- 上架候选：按 D0、D7、D28 复测；不以单日促销、断货或异常订单外推。
