# 环境配置与恢复指南

本 Skill 支持两种工作方式：

1. **离线证据分析**：用户提供候选、截图、导出、PDP 信息和供应商资料；不需要登录 Ozon。
2. **人工浏览器辅助读取**：用户在自己的浏览器中登录 Ozon Seller Portal，Skill 仅基于可见页面或用户导出的材料分析；不保存密码、Cookie 或令牌。

运行前先执行：

```text
python scripts/check_environment.py
```

需要同时检查人工浏览器状态或证据目录时，由可信宿主提供脱敏探测状态，或在项目目录中指定证据目录。环境检查不登录、不安装、不改配置、不输出凭据值。

## python-runtime

- 用途：运行只读环境检查器；支持离线证据整理与本地结构化检查。
- 支持版本：Python 3.10 或更高版本。
- 官方主页：https://www.python.org/
- 官方文档：https://docs.python.org/3/using/windows.html
- 下载地址：https://www.python.org/downloads/
- 登录网址：不需要。
- 凭据入口：不需要。
- 配置步骤：
  1. 从 Python 官方下载页安装 Python 3.10 或更高版本。
  2. 在终端执行 `python --version`，确认版本符合要求。
  3. 执行 `python scripts/check_environment.py`，确认检查器可运行。
- 凭据存储：不适用。
- 验证方式：只读取 Python 版本；不访问网络。
- 过期、权限、额度处理：不适用；版本过低时升级 Python 后重新检查。
- 轮换和撤销：不适用。
- 核验日期：2026-11-19。

## ozon-browser-session

- 用途：读取用户自己已登录的 Ozon Seller Portal 页面、前台 PDP 和履约信息。
- 官方主页：https://seller.ozon.ru/
- 官方文档：https://docs.ozon.ru/global/
- 登录网址：https://seller.ozon.ru/
- Token/Key/OAuth 入口：本模式不需要提供 Token 或 API Key。
- 登录后路径：Seller Portal → Analytics → 按当前研究选择搜索分析或热销商品报表；前台 PDP 使用对应商品 URL。
- 权限与 scope：只需要用户账户本来拥有的页面访问权限；不额外授权、不索取管理员权限。
- 配置步骤：
  1. 在用户自己的浏览器中访问官方登录页并完成登录。
  2. 打开所需报表或 PDP，确认查询词、统计窗口、筛选条件和核验城市可见。
  3. 保存或提供包含上述上下文的原始截图、导出或文本快照。
  4. 若出现 Qrator、Captcha、滑块、307 后转 403 或其他人机验证，停止自动化读取，由用户手动完成验证后重新检查。
- 凭据存储：密码、Cookie、会话和令牌只留在用户自己的浏览器或 Ozon 官方系统；不得粘贴到对话、Skill 文件、脚本或日志。
- 验证方式：人工浏览器中目标报表或 PDP 正常打开，且能记录查询词、筛选、窗口和页面时间。
- 过期、权限、额度处理：登录失效时在官方登录页重新登录；权限不足时由账户管理员在 Ozon 官方后台处理；服务故障时改用用户导出的材料并标“部分验证”。
- 轮换和撤销：在 Ozon Seller Portal 的账号安全或会话管理页面退出不需要的会话；页面名称以官方当前界面为准。
- 核验日期：2026-11-19。

## evidence-directory

- 用途：保存候选证据包、原始快照、PDP、供应商资料与经济模型。
- 官方主页：https://www.workbuddy.cn/docs/workbuddy/Overview
- 官方文档：https://www.workbuddy.cn/docs/workbuddy/Overview
- 登录网址：不需要。
- 凭据入口：不需要。
- 配置步骤：
  1. 选择用户确认的项目内目录，不使用个人目录、系统目录或未授权路径。
  2. 按 `evidence-schema.md` 创建候选目录和 `00_manifest.json`。
  3. 保存原始快照、PDP、供应商规格、经济模型和 D0/D7/D28 记录。
- 凭据存储：不适用。
- 验证方式：只检查目录是否存在和可写；不创建、覆盖或删除文件作为环境检查的一部分。
- 过期、权限、额度处理：目录不可写时只输出待保存清单，标记“部分验证”；恢复权限后再落盘并补齐路径。
- 轮换和撤销：不适用。
- 核验日期：2026-11-19。

## 功能级降级

| 功能 | 失败条件 | 降级方式 | 用户补充 | 限制与证据标签 | 恢复方式 | 停止条件 |
|---|---|---|---|---|---|---|
| 平台数据读取 | 未登录、权限不足、服务错误、人机验证 | 分析用户提供的截图、导出或人工读数 | 查询词、窗口、筛选、时间与快照 | 不确认实时状态；标“部分验证” | 恢复人工登录会话后重检 | 无材料却要求需求或成交结论 |
| PDP 核验 | 页面不可读、动态加载失败、无实体绑定 | 保留候选和待补证清单 | PDP URL、规格、包装、ETA、发货地截图 | 不推断规格与兼容；标“未验证” | 获得可访问 PDP 后重跑 G2/G3 | 要求采购或单点利润但无 PDP |
| 证据落盘 | 无写入权限或用户拒绝保存 | 输出目录、manifest 和文件清单 | 可写项目目录或对话内记录确认 | 不声称证据包已完成；标“部分验证” | 提供目录后保存并补路径 | 要求审计包但没有任何存储位置 |
| 环境检查 | Python 缺失或版本低 | 人工记录可用条件和缺口 | 用户提供版本或材料 | 不给正式 ready 结论；标“部分验证” | 安装兼容 Python 后重检 | 用户要求正式环境验证 |
