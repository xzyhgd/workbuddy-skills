# 证据记录模板

每个候选 SKU 族使用一条可追溯记录。所有数字必须包含来源与抓取日期。

## 1. 基本定义

| 字段 | 内容 |
|---|---|
| 候选名称 | 可采购 SKU 族，而非泛类目 |
| 目标品牌 / 机型 | 例如 Creality Ender 3 V2 |
| 功能类型 | 维修、易损替换、升级、耗材、维护 |
| 兼容边界 | 尺寸、接口、电压、左右版本、代际、固件等 |
| 决策状态 | P0 / P1 / P2 / 待补证 |

## 2. 需求侧

| 字段 | 内容 |
|---|---|
| 社区来源 | URL、页面标题、抓取日期 |
| 装机代理 | 认领量、保有量或其他可复现代理 |
| 内容强度 | 文章数、帖子数、内容数 / 装机代理 |
| 主题样本 | 原文标题、链接、日期、升级 / 维修 / 痛点标签 |
| 数据边界 | 登录要求、动态加载、样本偏差、不能代表全市场 |

## 3. Ozon 供给侧

| 字段 | 内容 |
|---|---|
| 检索词 | 泛词、精确型号词、零件号、俄语同义词 |
| 搜索快照 | URL 或可复现检索条件、抓取日期 |
| 链接数 | 可辨认的真实商品链接数 |
| 独立卖家数 | 同款 / 同类独立卖家数量或区间 |
| 评论分布 | 每条链接评论数；标注为累计评论 |
| 价格带 | 最低、主流、高客单，单位 ₽ |
| 可售状态 | 在售、缺货、预售、跨境长时效 |
| 混杂说明 | 非目标机型、无关类目、跨型号聚合等 |

## 4. 痛点证据

| 字段 | 内容 |
|---|---|
| 商品链接 | 对应 Ozon 商品或外部页面 |
| 星级与日期 | 尽量保留原始上下文 |
| 原文 | 俄文原文，不擅自改写 |
| 中文释义 | 明确标注为翻译 |
| 痛点标签 | 兼容、安装、质量、包装、耐久、物流、售后 |
| 样本边界 | 抽样范围、样本量、不可泛化说明 |

## 5. 行动设计

| 字段 | 内容 |
|---|---|
| 目标价带 | 以 ₽ 为主，必要时再折算人民币 |
| 首测假设 | 首批数量、试水期限、可承受资金占用 |
| 验货清单 | 关键尺寸、材料、附件、通电 / 装配检查 |
| 上架要点 | 俄语标题词、兼容清单、主图要展示的规格 |
| 退出条件 | 转化、退货、差评、价格战、断供等触发阈值 |
| 置信度 | 高 / 中 / 低，并说明缺少什么证据 |
