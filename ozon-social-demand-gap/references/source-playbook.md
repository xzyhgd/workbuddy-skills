# 数据源与复核操作手册

## 数据源层级

### A. 需求侧

1. **机型社区 / 论坛：** 用于装机代理、内容量、维修 / 升级线索。3DToday 等公开机型库优先按机型页逐条记录。
2. **俄语社媒 / 视频平台 / 社群：** 用于获取问题原话和内容主题；记录可复现链接与登录要求。
3. **品牌与产品资料：** 用于确认机型代际、零件规格、官方兼容边界；不能替代真实需求证据。

### B. 供给侧

1. **Ozon 搜索与商品页：** 用于链接数、卖家数、累计评论、价格带、库存状态、买家反馈。
2. **供应商规格资料：** 用于验证零件号、尺寸、接口和包装清单。
3. **其他俄区货架 / 搜索：** 仅作为交叉线索，必须和 Ozon 结论区分。

## Ozon 检索词矩阵

每个候选至少覆盖四类词：

1. 泛需求词：`<品牌> <机型> запчасти`、`<机型> апгрейд`；
2. 精确部件词：`двойной Z винт <机型>`、`direct drive <机型>`；
3. 型号 / 零件号：例如 `Sprite Extruder Ender 3`；
4. 俄语同义词与规格词：`экструдер`、`сопло`、`горячий конец`、`ремень`、`плата`、`набор`、尺寸或电压。

用泛词发现市场语言与污染结果，用精确词确认真正供给。若泛词自动进入无关类目，不能据此宣称无货。

## 跨国供应链反向映射策略（破解国内搜不到副厂件）

当在 1688、国内汽配城或外贸工厂端找不到俄方对应的“副厂/平替件”时，严禁直接放弃，必须执行“三阶反向映射法”：

```
[俄方终端称呼]                  [技术原厂/国际标准]              [中国工厂出厂名]
Планар 44Д (Planar 44D)   ──▶   Eberspächer Airtronic D4   ──▶  埃贝赫 D4 鼓风机总成 / 5KW风机
сб.1881-01 / 24V                (德国埃贝赫，俄方逆向源头)       (河北沧州/浙江台州产业带通用名)
```

1. **第一阶：查俄方设备的逆向技术母本**  
   - 俄罗斯/苏联系设备（无论柴暖、机床、商用车还是五金设备）普遍有深厚的德系（Bosch、Eberspächer、Webasto）、日系或美系技术授权或测绘逆向渊源；
   - 查找该俄文型号在技术手册中对应的国际/欧洲原厂标杆（如 Planar 44D 对应 Eberspächer D4，Binar 对应 Webasto Thermo Top）。
2. **第二阶：查中国产业带通用叫法**  
   - 中国工厂极少用俄文品牌建产品库，通常以“国际大牌平替”或“功率/尺寸通用名”命名；
   - 常见的映射关键词模式：`适用 [国际品牌] [机型代码] [部件名]`（例：`适用 埃贝赫 D4 采暖风扇`、`D2/D4 无刷风机总成`）。
3. **第三阶：机械与电气参数反向核验**  
   - 拿俄方拆解图中的物理参数（工作电压 12V/24V、风轮直径、安装孔距、轴径、额定转速 4,500 RPM、引脚线序）与国内工厂图纸逐一比对，验证 100% 物理互换性。

## 3DToday 机型页数据提取提示

- 先使用品牌页和 `sort=owners` 建立相对装机代理；
- 分页抓取时检查页面总页数、机型数量和缺页；
- 若直接 fetch 的 DOM / 文本结构不稳定，可从 HTML 中按 `models_list__elem__title` 分段，再提取机型名、`владельц` 和 `статей` 数；
- 动态“Показать больше”可能一次只加载极少内容。不能因无法全量抽取就估计升级 / 维修文章比例；如实写为标题级观察或未完成。

## 买家评价抽样

- 先浏览 1–3 星、带图、近期评价和问答；
- 提取原文时保留商品链接、星级、日期和版本；
- 将“用户反映了什么”与“本研究如何解释”分开；
- 采样不代表总体时，明确样本数和选择规则。

## 访问受限处理

官方页面、卖家教育页面或社媒出现反自动化挑战、无限重定向、登录墙时：

- 不绕过，不求解挑战，不改 TLS，不找未授权代理；
- 把访问受限记录为可复现条件；
- 只将可验证的独立页面当作证据；
- 不把搜索摘要或第三方转述写成官方原文。

## 汇率与财务口径

- Ozon 店铺价格币种、Ozon 展示币种与折算币种必须分开写；
- 汇率写明来源与日期，不混用不同日期；
- 需要折人民币时，保留原始 ₽ 金额、汇率、公式和四舍五入规则；
- 财报、行业统计仅用于背景，不直接替代产品级需求证据。
