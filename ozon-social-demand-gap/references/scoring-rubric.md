# P0 / P1 / P2 评分口径

本口径用于保证决策一致性，不用于生成看似精确的伪量化分数。先判断硬性排除项，再用六个维度进行分档。

## 硬性排除项

命中任一项时，默认 P2 或要求补证：

1. 兼容型号无法明确，且错误购买会导致高退货；
2. 同质化卖家密度高、低价竞品已密集进入；
3. 无装机 / 社媒 / 搜索 / 成交等任何需求支撑；
4. 产品存在强原厂锁定、侵权、合规或安全风险；
5. FBS 运输、易碎、缺件、质控或售后成本吞噬毛利；
6. 所谓“供给缺口”只来自一个被污染的泛关键词搜索。

## 六维判断

| 维度 | 强信号 | 中性信号 | 弱信号 |
|---|---|---|---|
| 装机基础 | 高保有量或多来源明确存量 | 有机型 / 用户迹象但规模不明 | 无条目或只有营销信息 |
| 社媒讨论 | 持续内容、具体维修 / 升级问题 | 零散讨论 | 无法找到可复现讨论 |
| Ozon 供给 | 少卖家、关键版本或价格带缺口 | 有少量竞品 | 多卖家、同质化低价铺货 |
| 需求沉淀 | 同类产品已有适度成交 / 评论 | 评论很少但外部支撑存在 | 全部零评论且无外部支撑 |
| 痛点可解 | 痛点具体、规格化、可在详情页预防 | 有问题但需要较多说明 | 痛点模糊、维修复杂、售后重 |
| 经济性 | 价带可覆盖履约与质控 | 需控制采购价 / 包装 | 低客单或高退货风险 |

## 分级决策

### P0：首测

满足以下条件：

- 没有硬性排除项；
- 装机基础和社媒讨论至少一项强，另一项不弱；
- 供给侧存在可解释的薄弱环节，而不是单纯低评论；
- 已拆到具体规格与兼容边界；
- 能提出首批、验货、标题关键词和退出条件。

### P1：补证或观察

适用于以下情形：

- 有需求迹象，但供应竞争、价格带或兼容性尚不清晰；
- 有货架空档，但装机 / 社媒支撑不足；
- 评论正文或真实成交尚未验证；
- 应通过精确关键词、具体零件号、样品或供应商规格表补证。

### P2：不进入

适用于以下情形：

- 假空白：低评论但多卖家，或无需求侧支撑；
- 价格战、低价同质化、老旧链接垄断；
- 兼容复杂、质量不可控、退货风险高；
- 目标机型衰退或被新型号替代；
- 证据无法复现，且无法通过独立来源补强。

## 置信度写法

- **高：** 至少两类独立需求证据 + 供给快照 + 商品 / 评论验证；
- **中：** 有装机或社媒证据，且完成精确 Ozon 复核，但仍缺成交或兼容数据；
- **低：** 单来源、样本少、受访问限制或只能得到间接信号。

不得以“总分 87.3 分”等形式掩盖来源质量差异。
