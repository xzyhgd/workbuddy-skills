# 认证详情

> **首次使用 / 遇到 `AUTH_REQUIRED` 时必读**：命令被鉴权闸门拦截会输出 `AUTH_REQUIRED:<url>`，
> 此时必须按下方「鉴权交互流程」引导用户完成授权，不要反复重跑命令「验证」。
> 其余情况（诊断状态 / 手动设置 key / 退出登录）按需查阅本文对应小节。

## 诊断与退出

| 操作 | 命令 |
|------|------|
| 查看状态 | `westock auth status` |
| 退出登录 | `westock auth clear` |

## 鉴权交互流程（Agent 必读）

### 第一步：检查状态（立即返回）

```bash
westock auth status
```

| 输出 | 处理方式 |
|------|---------|
| `READY` | ✅ 已鉴权，直接执行用户任务，无需后续步骤 |
| `AUTH_REQUIRED:<url>` | 向用户展示授权链接（提示用系统浏览器打开），随后**立即进入第二步** |
| `ERROR:*` | 告知用户具体错误信息，并引导走**第四步人工兜底** |

> **幂等**：未鉴权时 `status`（以及任意数据命令）会复用同一个未过期的授权链接，
> 不会因重复执行而作废用户正在扫的码；若用户已授权完成，会自动领取凭证（返回 `READY`），
> 不会再展示已失效的链接。链接有效期 5 分钟，到期后才重新生成。

### 第二步：等待授权完成

> ⚠️ **展示链接后立刻开始等待，不要停下来问用户「授权好了吗」。**
> 等待是**自动**的：用户只需扫码，Agent 自行轮询到结果出现为止，无需用户回报。

> ⏰ **授权成功后必须在链接有效期内完成 `fetch` 领取凭证**：授权页显示「授权成功」只是
> 标记了授权完成，专属 APIKey 是在 `fetch`（即 poll）时才生成的。若用户已授权但 Agent
> 一直不 `fetch`，链接 5 分钟过期后本次授权作废，需重新发起。`--wait 300` 已覆盖整个窗口。

**推荐：单命令内置轮询**（一条命令等到结果）：

```bash
westock auth fetch --wait 300
```

| 输出 | 处理方式 |
|------|---------|
| `TOKEN_READY` | ✅ 授权完成，继续执行用户任务 |
| `ERROR:cancelled` | 用户已主动取消，**立即停止**；询问是否重新发起（回第一步） |
| `ERROR:expired` | 授权链接已过期（5 分钟），回到第一步重新发起 |
| `ERROR:not_authorized` | 等待超时（用户未完成），告知用户后回到第一步或询问是否继续 |
| `ERROR:*` | 告知用户错误信息，引导走第四步人工兜底 |

**兼容：手动轮询脚本**（宿主不支持长等待时）：

```bash
for i in $(seq 1 30); do
  out=$(westock auth fetch)
  case "$out" in
    TOKEN_READY)   break ;;      # 授权完成
    ERROR:expired) break ;;      # 超时，回到第一步重新发起
    *)             sleep 10 ;;   # 含 not_authorized，继续等待
  esac
done
```

### 第三步：授权链接展示模板

第一步输出 `AUTH_REQUIRED:<url>` 时向用户展示，并提示**用系统浏览器打开**：

> 🔑 **需要先完成专属 APIKey 授权**
>
> 请**用系统浏览器**打开以下链接完成授权：**[点击授权]({url})**
>
> ⏰ **授权链接有效期 5 分钟**
>
> 点击一次「同意授权」即可，**不要重复点击、刷新页面或再次打开同一链接**。

### 第四步：人工兜底

自动流程持续失败时，引导用户在授权页拿到 key 后手动设置：

1. 用户在浏览器完成扫码后，授权页会显示专属 APIKey
2. 用户将 APIKey 提供给 Agent
3. Agent 保存到本地：`westock auth set "<WZQ_APIKEY>"`

## 输出协议（机器可读）

| 输出 | 含义 |
|------|------|
| `READY` | 已鉴权 |
| `AUTH_REQUIRED:<url>` | 需要授权，首行为机器协议；次行 `NEXT:<命令>` 为下一步指令 |
| `TOKEN_READY` | 授权完成，key 已落盘 |
| `CLEARED` | 已清除本地 key |

## 错误说明

| 错误 | 含义 |
|------|------|
| `ERROR:no_code` | 未找到授权码，需重新执行第一步 |
| `ERROR:not_authorized` | 用户尚未在浏览器完成授权，继续轮询等待 |
| `ERROR:expired` | 授权码已过期（5 分钟）或已被领取，重新执行第一步 |
| `ERROR:cancelled` | 用户在授权页主动取消，本次授权已终止；如需继续请重新发起 |
| `ERROR:network:<详情>` | 网络请求失败，检查网络后重试 |
| `ERROR:http_<状态码>` | 接口返回非 2xx（如 `http_404`、`http_500`） |
| `ERROR:code_<业务码>:<说明>` | 后端返回业务错误，如 `code_1620053003:device code dev_id mismatch` |
| `ERROR:save_code_failed` | 授权码写入本地失败，检查用户目录权限 |
| `ERROR:save_token_failed` | key 写入本地失败，检查用户目录权限 |
| `ERROR:empty_key` | 返回的 key 为空 |
